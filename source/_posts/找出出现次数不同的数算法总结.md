# 数组中特殊出现次数问题：异或、数位统计与分组

在数组题中，经常会遇到这样一类问题：

```
大部分数字出现固定次数
少数数字的出现次数不同
要求找出这些特殊数字
```

解决这类问题的关键不是记住某段位运算代码，而是判断：

> 能否通过异或或按位取模，让正常数字的贡献全部抵消。

## 一、一个数字出现一次，其他出现两次

这是最简单的情况，直接异或：

```
public int singleNumber(int[] nums) {
    int ans = 0;

    for (int num : nums) {
        ans ^= num;
    }

    return ans;
}
```

因为：

```
x ^ x = 0
x ^ 0 = x
```

所有出现两次的数字都会消失，只留下出现一次的数字。

## 二、一个数字出现 p 次，其他出现 k 次

设目标数字出现 `p` 次，其他数字出现 `k` 次。

对每个二进制位统计 `1` 的数量，然后模 `k`：

\[ C_j\bmod k=(p\times b_j)\bmod k \]

其中 `b_j` 是目标数字第 `j` 位，只能为 `0` 或 `1`。

只要满足：

\[ \boxed{p\bmod k\neq0} \]

就可以恢复目标数字。

```
public int findNumber(int[] nums, int p, int k) {
    int ans = 0;
    int expected = p % k;

    for (int bit = 0; bit < 32; bit++) {
        int count = 0;

        for (int num : nums) {
            count += (num >>> bit) & 1;
        }

        if (count % k == expected) {
            ans |= 1 << bit;
        }
    }

    return ans;
}
```

常见情况：

| 目标次数 `p` | 其他次数 `k` | 判断余数         |
| ------------ | ------------ | ---------------- |
| 1            | 2            | `count % 2 == 1` |
| 1            | 3            | `count % 3 == 1` |
| 2            | 3            | `count % 3 == 2` |
| 2            | 5            | `count % 5 == 2` |

这里关键是 `p % k != 0`，不是 `k % p != 0`。

## 三、一个数字出现两次，其他出现一次

这个情况不能直接使用异或或数位取模。

异或会把目标数字消掉：

```
[2, 3, 3, 4]

2 ^ 3 ^ 3 ^ 4
= 2 ^ 4
= 6
```

数位统计同样无法解决，因为其他数字只出现一次，不存在大于 1 的 `k` 满足：

\[ 1\bmod k=0 \]

如果数字为任意整数，同时不排序、不使用额外空间，只能逐个候选检查，时间复杂度为 `O(n²)`。

如果额外保证：

```
数组长度为n+1
元素范围为[1,n]
```

则可以使用 Floyd 判圈，在 `O(n)` 时间、`O(1)` 空间内找到重复数字。

## 四、两个数字出现一次，其他出现两次

设两个特殊数字为 `a`、`b`。

全部异或后：

\[ xor=a\oplus b \]

取 `xor` 的最低有效位：

```
int lowbit = xor & -xor;
```

这个位在 `a` 和 `b` 中一定不同，因此可以将它们分到不同组。

```
public int[] findTwo(int[] nums) {
    int xor = 0;

    for (int num : nums) {
        xor ^= num;
    }

    int lowbit = xor & -xor;
    int a = 0;
    int b = 0;

    for (int num : nums) {
        if ((num & lowbit) == 0) {
            a ^= num;
        } else {
            b ^= num;
        }
    }

    return new int[]{a, b};
}
```

相同数字的两份副本二进制完全相同，一定进入同一组，然后在组内异或抵消。

## 五、两个数字出现 p 次，其他出现 k 次

这种情况可以推广前面的分组思想。

先逐位计数，找到满足：

```
count % k == p % k
```

的位。这个位上两个特殊数字恰好有一个为 `1`，因此它们会进入不同组。

分组之后：

```
第一组：一个特殊数字出现p次，其他出现k次
第二组：另一个特殊数字出现p次，其他出现k次
```

然后在每一组中使用数位计数模 `k`，分别恢复两个数字。

前提仍然是：

```
两个特殊数字不同
p % k != 0
```

## 六、三个数字出现一次，其他出现两次

全部异或只能得到：

\[ xorAll=a\oplus b\oplus c \]

这时不能直接通过一个 `lowbit` 确定三者如何分组。

可以枚举每个二进制位：

1. 按该位将数组分成两组。
2. 分别计算组内异或结果。
3. 将两个结果作为候选值。
4. 回到原数组检查候选是否确实只出现一次。
5. 找到一个特殊数字后，将问题退化为“两个数字出现一次”。

这里的 check 是必要的，因为一组可能包含两个特殊数字，组内结果是二者异或，不一定是实际存在的数字。

虽然仍然可以做到 `O(32n)` 时间和 `O(1)` 空间，但实现已经明显复杂。

## 七、数位统计法的适用规律

数位统计法适合：

```
正常数字的出现次数都能被k整除
只有一个异常数字的次数不能被k整除
```

它失效的主要情况包括：

- 正常数字只出现一次，无法通过取模消除。
- 异常数字也出现 `k` 的倍数次。
- 存在多个异常数字，各数位信息混合。
- 缺少可以将多个异常数字分开的条件。

数位统计只保留每一位出现多少次，不保留这些位属于哪个数字。例如不同数组可能拥有相同的逐位计数，却有不同的重复数字。

## 八、什么时候直接使用 HashMap

当异常数字数量增加、出现次数不统一，或者题目没有 `O(1)` 空间要求时，直接计数更合理：

```
Map<Integer, Integer> count = new HashMap<>();

for (int num : nums) {
    count.merge(num, 1, Integer::sum);
}
```

方案选择可以概括为：

| 场景                         | 推荐方法                   |
| ---------------------------- | -------------------------- |
| 一个 1 次，其他 2 次         | 全部异或                   |
| 一个 `p` 次，其他 `k` 次     | 数位计数模 `k`             |
| 两个 1 次，其他 2 次         | 异或后按 `lowbit` 分组     |
| 两个 `p` 次，其他 `k` 次     | 找不同位分组，再数位统计   |
| 三个异常数字                 | 分组、候选检查，或 HashMap |
| 异常数量不确定               | HashMap                    |
| 任意整数，一个重复、其他一次 | HashSet 或 `O(n²)` 检查    |
| 范围为 `[1,n]` 的重复数字    | Floyd 判圈                 |

位运算方法主要服务于严格的 `O(1)` 空间要求。没有这个限制时，HashMap 往往更简洁、通用，也更符合工程实践。
